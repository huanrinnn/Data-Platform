默认数据源连接失败的收尾说明

这份说明记录了本次从 DM8 切换到 MySQL 过程中，默认数据源 id=3 连接失败的根因、已完成的修复、验证结果，以及后续重建环境时需要保留的初始化动作。

日期：2026-07-31 状态：已修复并验证成功 范围：默认数据源 & MySQL 初始化

问题根因

这次失败不是单一原因，而是两层问题叠加：
  • 默认数据源 id=3 连接到的数据库是 dws，但 MySQL 里当时还没有创建这个 schema。
  • 之前的连接串和 seed 数据曾经残留过旧配置，导致排查时混入了认证失败、旧账号和旧 URL 参数等历史问题。

已完成修复

  • 默认 MySQL URL 补上了 allowPublicKeyRetrieval=true。
  • 默认 4 条数据源种子数据统一改为 qdata 账号。
  • MySQL 初始化脚本补上了 ods、dwd、dws、ads 的自动创建。
  • 本机 MySQL 中也已补齐这 4 个 schema，并验证 qdata 可以直接连接 dws。
